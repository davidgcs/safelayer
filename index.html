How to use it

  1. Upload a JPG, PNG, WebP, or PDF.
  2. Turn on grayscale and/or enter custom watermark text, then enable the wave pattern.
  3. Drag over IDs, numbers, signatures, addresses, or other data to create black redactions.
  4. Select Save and download. The watermark will repeat across every page.

Privacy: your file is processed in this browser and is not sent to a server by this version.

Note: redactions are rasterized in exported PDFs, so covered data does not remain selectable text.
