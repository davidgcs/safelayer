Safe Layer

Sanitización local de imágenes y PDF para compartir documentos con menor riesgo.
Procesamiento en tu navegador
Selecciona una imagen o PDF. Después, arrastra rectángulos negros sobre los datos que quieras ocultar.
No hay ningún documento cargado.

Cómo usarlo

1. Sube un JPG, PNG, WebP o PDF.

2. Activa escala de grises y/o escribe una marca de agua personalizada y activa el patrón diagonal.

3. En cada página, arrastra para crear tachados negros sobre DNI, número, firma, dirección u otros datos.

4. Pulsa Guardar y descargar. La marca se repetirá diagonalmente por toda la página.

Privacidad: el archivo se procesa en el navegador. No se envía a un servidor en esta versión.

Nota: la redacción se rasteriza en el PDF de salida, por lo que los datos cubiertos no quedan como texto seleccionable.
